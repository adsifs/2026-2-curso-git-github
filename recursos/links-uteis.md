# 🔗 Links Úteis

Material complementar para aprofundar os estudos.

## 📖 Documentação oficial

- [Git — documentação oficial](https://git-scm.com/doc) — referência completa de todos os comandos;
- [Pro Git (livro gratuito, em português)](https://git-scm.com/book/pt-br/v2) — **o** livro de Git, disponível online de graça;
- [GitHub Docs (em português)](https://docs.github.com/pt) — documentação oficial do GitHub.

## 🎮 Tutoriais interativos (aprenda praticando)

- [Learn Git Branching](https://learngitbranching.js.org/?locale=pt_BR) — visualiza branches e merges como um jogo. **Altamente recomendado** para o Módulo 5;
- [GitHub Skills](https://skills.github.com/) — cursos práticos oficiais do GitHub, feitos dentro de repositórios reais;
- [Oh My Git!](https://ohmygit.org/) — jogo open source para aprender Git.

## 🛠️ Ferramentas

- [gitignore.io](https://www.toptal.com/developers/gitignore) — gera arquivos `.gitignore` para qualquer linguagem/IDE;
- [GitHub Desktop](https://desktop.github.com/) — interface gráfica oficial (depois de dominar o terminal!);
- [Git no VS Code](https://code.visualstudio.com/docs/sourcecontrol/overview) — guia da integração Git do VS Code;
- [GitHub Student Developer Pack](https://education.github.com/pack) — benefícios gratuitos para estudantes (GitHub Pro incluso).

## 📄 Referências rápidas

- [Cheatsheet oficial do GitHub (PDF, em português)](https://training.github.com/downloads/pt_BR/github-git-cheat-sheet.pdf);
- [Guia de Markdown do GitHub](https://docs.github.com/pt/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

## 🎯 Para ir além (após o curso)

Tópicos que **não** cobrimos e que valem estudo futuro, em ordem sugerida:

1. `git stash` — guardar mudanças temporariamente;
2. `git rebase` — reescrever histórico (alternativa ao merge);
3. Tags e releases — marcar versões (`v1.0`, `v2.0`...);
4. GitHub Actions — automação e integração contínua (CI);
5. GitHub Pages — hospedar sites estáticos de graça (ótimo para portfólio!);
6. [Conventional Commits](https://www.conventionalcommits.org/pt-br/) — padrão profissional de mensagens de commit.
