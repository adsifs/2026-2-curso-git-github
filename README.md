# 📚 Curso de Git e GitHub

> Material de apoio para alunos que desejam aprender Git e GitHub — do básico ao avançado, com exemplos práticos.

## 🎯 Objetivo

Ao final deste curso, você será capaz de:

- Entender **o que é controle de versão** e por que ele é essencial;
- Criar e gerenciar repositórios **Git** na sua máquina;
- Publicar e sincronizar seus projetos no **GitHub**;
- Organizar e entregar os exercícios das disciplinas usando Git;
- Trabalhar com branches e resolver conflitos simples;
- Seguir boas práticas usadas no mercado de trabalho.

Siga os módulos **na ordem**. Cada um assume que você concluiu o anterior.

## 📦 Como este material será usado nas disciplinas

1. Cada aluno terá **um repositório no GitHub por disciplina**;
2. Os programas de exemplo e exercícios de cada aula devem ser **commitados e enviados** (`push`) para o repositório;

## ❓ Dúvidas

- Consulte primeiro o [guia de solução de problemas](recursos/solucao-de-problemas.md);
- Abra uma **Issue** neste repositório (você aprenderá como no [Módulo 6](06-fluxo-de-trabalho/README.md));
- Ou pergunte em aula. 🙂
